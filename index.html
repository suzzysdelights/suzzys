Setup
Supabase sync Not connected
Connect a free Supabase database so your orders are safe and accessible from any device — including your phone.
One-time database setup (5 min)
1
Create a free Supabase account
Go to supabase.com → New project → pick a name → choose region Europe (Frankfurt) — closest to Kenya.
2
Run this SQL in the SQL editor
In your project → SQL Editor → New query → paste this → Run:
create table orders (
  id uuid default gen_random_uuid() primary key,
  created_at timestamptz default now(),
  customer text not null,
  phone text,
  product text not null,
  delivery_date date,
  ingredients jsonb default '[]',
  labour numeric default 0,
  margin_pct numeric default 30,
  deposit_pct numeric default 50,
  total numeric default 0,
  deposit_paid boolean default false,
  balance_paid boolean default false,
  notes text,
  status text default 'pending'
);
